# AI-Powered Lost & Found Management System

A smart web-based Lost & Found Management System designed to help users report lost or found items, search reported items, and identify possible matches using item details.

## Features

- Report lost items
- Report found items
- Search reported items
- Filter items by status
- AI-style item matching
- Match confidence percentage
- Category, colour and location based comparison
- Local browser storage
- Responsive web interface

## How It Works

1. **Report** – Users submit details about a lost or found item.
2. **Analyse** – The system compares important item information.
3. **Match** – Possible lost and found connections are identified.
4. **Recover** – Users can use the matching information to help recover the item.

## AI Matching

The current prototype uses a lightweight rule-based matching engine.

It compares:

- Item name
- Category
- Colour
- Location
- Description

The system calculates a match confidence percentage based on the similarity between lost and found reports.
